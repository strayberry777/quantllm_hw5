# 回测引擎：设计与验证

## 1. 结构

```text
MarketData（bt/data.py）       读 7 张宽表，派生：可交易、上市天数、涨跌停价、封板、复权、估值价
    │
策略（bt/strategies.py）        只输出目标权重矩阵 W[日期, 证券]；整行 NaN = 当天不调仓
    │
Backtester（bt/engine.py）      逐日循环：除权调股数 → 开盘按 W[t-1] 调仓 → 收盘估值
    │
summarize（bt/metrics.py）      年化、波动、夏普、最大回撤、卡玛、胜率、换手、费用拖累、相对基准超额
```

策略和撮合完全分开：策略看不到成交结果，引擎也不知道信号是怎么来的。所以同一个引擎可以跑 5DR、动量、买入持有，
也可以被一个完全独立的公式验证。

## 2. 一天之内发生什么

| 时点 | 动作 |
|---|---|
| 开盘前 | 若当天除权除息，持股数 × (今日 cumadj / 昨日 cumadj)，即红利再投资口径 |
| 开盘 | 读取**前一交易日收盘**给出的目标权重；按开盘价计算组合价值与目标股数 |
| | 取整：主板 / 创业板 100 股；科创板不足 200 股不买，超过按 1 股递增 |
| | 剔除：停牌（当天无成交）、开盘封涨停的买单、开盘封跌停的卖单 |
| | 先卖后买；买入总额超过现金时按比例缩减 |
| | 没成交的那几只，目标顺延到下一个交易日（其余证券不动） |
| | （可选）成交额上限：单只当天成交 ≤ 前一交易日成交额 × 上限比例，超出部分顺延 |
| 收盘 | （可选）回测最后一天按收盘价清空持仓；收盘跌停或停牌的卖不出，计入未成交 |
| | 按收盘价估值（停牌股按最近收盘价），记录净值、现金、仓位、换手、费用 |

**为什么是「收盘信号 → 次日开盘成交」**：信号要用到第 t 日收盘价，收盘那一刻已经买不到了。
用收盘价成交等于偷看了答案（前视偏差）。T+1 也自然满足：买入的股票最早下一个交易日开盘才能卖。

## 3. 费用

| 项目 | 费率 | 方向 |
|---|---|---|
| 佣金 | 0.03%，单笔最低 5 元 | 双边 |
| 过户费 | 0.001% | 双边 |
| 印花税 | 0.1%；2023-08-28 起 0.05% | 卖出 |
| 滑点 | 5bp（买价上浮、卖价下调） | 双边 |

一次完整买卖（2023-08-28 之后）大约 0.03×2 + 0.001×2 + 0.05 + 0.05×2 ≈ **0.21%**。

课程作业规格的费用为佣金万一（双边、无最低）+ 印花税万五（卖出），一次完整买卖 **0.07%**，见 [ASSIGNMENT.md](ASSIGNMENT.md)。

## 4. 怎么证明它算对了

**单元测试（`tests/test_engine.py` 14 项 + `tests/test_api.py` 9 项，合成数据）**

`test_api.py` 另外检查：平台逐日回调与矩阵方式结果完全一致、策略拿到的历史数据最后一天就是当天、做空和加杠杆会报错、6 个模板都能运行。

| 测试 | 检查什么 |
|---|---|
| 成交时点 | 第 t 日信号在第 t+1 日开盘成交，信号日净值不受影响 |
| 买入持有 | 净值之比 = 后复权价之比（含一次除权） |
| 费用 | 佣金、最低佣金、过户费、印花税逐项核对；净值 = 本金 − 全部费用 |
| 印花税切换 | 2023-08-25 为 0.1%，2023-08-28 为 0.05% |
| 滑点 | 买在 10.01、卖在 9.99 |
| 整手 | 主板 303 股取整为 300；科创板 303 股照买；科创板 121 股买不了 |
| 涨跌停 | 开盘一字涨停买不进；一字跌停卖不出，次日顺延卖出；关闭顺延时目标作废 |
| 停牌 | 停牌期间按最近收盘价估值；复牌第一天执行卖出 |
| 新股 | 上市前 5 日不设涨跌幅 |
| 交叉验证 | 不定期调仓、带除权的 6 只股票，引擎 = 独立公式 |
| ST 推断 | 连续收在 ±5% 限价被标记为 ST，价格超出 ±5% 后解除；科创板不推断 |
| 成交额上限 | 每天最多成交前一日成交额的 10%，一笔大单分 5 天成交 |
| 期末清仓 | 最后一天按收盘价卖出，费用按万一佣金 + 万五印花税计算 |

**真实数据交叉验证（`scripts/validate_engine.py`）**

另写一个不经过引擎的向量化公式：

```text
隔夜增长  g_on = 现金权重 + Σ ω_i · O_i,t / C_i,t-1      ω 为上一日收盘的漂移后权重
日内增长  g_in = 现金权重 + Σ w_i · C_i,t / O_i,t
NAV_t   = NAV_t-1 · g_on · g_in
```

零费用、分数股、关闭涨跌停时，两者必须相等。公式假设调仓日都能成交，所以只在样本期内从未停牌的 2,367 只股票上比较：

| 案例 | 交易日 | 最大相对误差 |
|---|---:|---:|
| 5DR 每 5 日调仓 | 1,643 | 7.5e-15 |
| 5DR 每日调仓 | 1,643 | 4.2e-14 |
| 股票池等权 每 5 日 | 1,643 | 1.0e-14 |
| 5 日动量 每 5 日 | 1,643 | 1.0e-14 |
| 买入持有 长鑫科技 | 54 | 0 |
| 买入持有 浦发银行（多次分红） | 1,643 | 2.2e-16 |

误差都在浮点精度范围内。完整结果见 `outputs/validation/engine_vs_formula.csv`。

## 5. 已知简化

- 只在开盘成交一次，不模拟盘中；不建模冲击成本（单股策略 100 万、5DR 每只约 30 万元）
- 除权时持股数按比值连续调整（等价于红利再投资），所以会出现零股；清仓时零股一并卖出
- 停牌股按最近收盘价估值；退市股最后一个价格一直保留（样本期内对结论影响很小）
- 数据没有 ST 标记，ST 股 5% 涨跌幅只能靠「一字板」规则兜底
