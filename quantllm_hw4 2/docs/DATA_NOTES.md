# 数据说明

课程「第四讲回测数据（2020-01-02 至 2026-10-16）」，7 个 Feather 文件，每个都是「交易日 × 证券」的宽表：
第一列 `date`，其余 5,451 列为证券代码（如 `000001.SZ`）。

| 文件 | 含义 |
|---|---|
| `open / high / low / close` | 不复权价格（元） |
| `amt` | 成交额（元） |
| `num_trades` | 成交笔数（本回测未使用） |
| `cumadj` | 累计复权因子 |

1,643 个交易日；深市 3,038 只、沪市 2,413 只，没有北交所。原始数据不入库（体积大，也可能受授权限制），
放到 `raw/` 下即可运行。下载包 `feathers.zip` 的 SHA-256：
`5766950f2a105244867b842709cf4bad890e4e11df0eebeeaa4fec42dc05803d`。

## 用数据核对过的口径

| 问题 | 结论 | 怎么核对的 |
|---|---|---|
| 复权方式 | 后复权价 = 价格 × cumadj | 平安银行 2020-05-28 除息：原始涨幅 0.54%，× cumadj 后 2.27%，与含息收益一致 |
| 停牌 | `amt == 0`（或缺失）且价格沿用前收盘 | 共 23,229 个「有价无量」格子 |
| 涨跌幅 | 主板 10%；科创板 20%；创业板 2020-08-24 起 20%；上市前 5 个交易日不设限 | 用除权后前收盘作参考价，7,790,312 个交易日中只剩 160 个越界（多为退市整理期，不影响结论） |
| OHLC 一致性 | 无 high < max(open, close) 或 low > min(open, close) | 全表扫描 |
| ST 股 | 数据没有 ST 标记 | 用「一字板」规则兜底：开高低收同价且高开视为买不进，低开视为卖不出 |

`cumadj` 存在 1e-6 量级的舍入抖动（相邻两日不完全相等），引擎按比值调整持股数，影响可以忽略，
真实数据交叉验证里也已包含这一点。

## 长鑫科技（688825.SH）

- 2026-07-27 在上交所科创板上市；发行价 8.66 元，首日开盘 49.5 元
- 样本内 54 个交易日（2026-07-27 至 2026-10-16）；首日成交额 1,411.9 亿元，是 2020 年以来科创板新股首日的最高值
- `cumadj` 全程为 1（未除权）；首日收盘 49.00，最高收盘 61.80（2026-08-17），最后一日收盘 45.02
- 日收益标准差 3.92%；2026-10-16 的 `num_trades` 为空（未使用该字段）
