# 第 0 轮反思（6 个内建因子作为基准）

工具修正：第一次运行时重复检测把「极端度」的原始值（5 日收益）当成因子本身，误判它和 5DR 相关 −1。
修正为用排名变换后的值比较，并只和「更早」的因子比较。修正发生在任何迭代之前，第 0 轮重新跑了一次。

观察（训练期 2020-01 至 2022-11 / 验证期 2023-01 至 2024-11；验证期基准夏普 0.22、最大回撤 −33.1%）：

- 四个目标选出的第一名不同：IC → EXT5；夏普、回撤、混合 → LOWVOL20（夏普上 ILLIQ20 几乎并列）
- EXT5 的 IC 最强（t 9.2），但做多最高组只和基准打平：它擅长剔除坏股票，不擅长挑好股票
- LOWVOL20 回撤最小（−16.4%，基准 −33.1%），两期夏普都高于基准，是「控回撤」方向最可靠的起点
- ILLIQ20 超额最高（验证期 +10.6%），但回撤 −34.7% 不比基准好
- LOWVOL20 与 ILLIQ20 只相关 0.37，组合可能同时拿到两边的好处
- MAX20 与 LOWVOL20 相关 0.86，是重复信号；REV5、MOM20 两期都为负，放弃这个方向

下一轮计划：
1. LOWVOL20 + ILLIQ20 等权组合（冲混合目标）
2. 更长窗口的低波动（60 日），看能否进一步压回撤、降换手
3. 低贝塔（60 日），另一种「低风险」定义，检验低波动的效果是否来自对市场的低敞口
4. 低波动 + 极端度组合：用极端度剔除两头，再在中间挑低波动
5. 成交额异常（近 5 日 / 近 60 日）：一个全新的注意力方向，检验「被关注的股票之后跑输」
